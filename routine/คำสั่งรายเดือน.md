# คำสั่งสำหรับ routine วันที่ 1 ของทุกเดือน (repo `nutdregs19/aomdiwa`)

คุณกำลังเขียน "บทสรุปรายเดือน" ของแอปออมดิวะ อ่าน `CLAUDE.md` ในรากของ repo ก่อน แล้วทำตามนี้

## กติกาที่ห้ามหลุด
- ทุกตัวเลข ทุกข่าว ต้องมาจากหน้าเว็บที่ **เปิดอ่านจริงในรอบนี้** ห้ามตอบจากความจำ ห้ามแต่งตัวเลข วันที่ หรือลิงก์
- หาไม่ได้ให้เขียนว่า "ไม่พบข้อมูล" หรือไม่ใส่ข้อนั้นเลย
- ภาษาไทยแบบคนทั่วไปอ่านรู้เรื่อง ศัพท์เฉพาะให้อธิบายสั้น ๆ ในวงเล็บ
- เป็นกลาง ไม่มีคำว่า "ควรซื้อ" "ควรขาย" แอปนี้ไม่ใช่ที่ปรึกษาการลงทุน
- ห้ามแก้ไฟล์อื่นนอกจากที่ระบุด้านล่าง ห้ามลบไฟล์ ห้ามเขียนทับไฟล์เดือนเก่า

## ขั้นตอน
1. `npm ci` แล้ว `node scripts/fetch-data.ts` เพื่อให้ราคาเป็นปัจจุบัน จากนั้น `node scripts/show.ts` ดูตาราง
2. เลือกหุ้นที่จะเขียน: ทุกตัวที่ **ผ่านครบ 3 ด่าน** + ทุกตัวที่ **ติดธงอยู่** + ตัวที่ต่ำกว่าจุดสูงสุดเกิน 20% + 8 ตัวหลัก
   (NVDA RKLB PLTR GOOGL RBRK ACHR ONDS SPCX) รวมไม่เกิน ~20 ตัว
3. แต่ละตัว ค้นจาก ~6 สัปดาห์ล่าสุด: ผลประกอบการไตรมาสล่าสุด (รายได้ กำไร/ขาดทุน เงินสด เป้าที่บริษัทให้) ข่าวหลัก
   และถ้าราคาต่ำกว่าจุดสูงสุดมาก ให้หาเหตุผลจริงที่ราคาตก · แหล่งที่ควรใช้: หน้านักลงทุนสัมพันธ์ของบริษัท, SEC, Reuters, AP, Yahoo Finance
4. ตัดสินธง: ติดธงเฉพาะเมื่อ **พื้นฐานเปลี่ยน** (ลดเป้าแรง, ปัญหาบัญชี, เสียลูกค้าหลัก, เงินสดใกล้หมด/ออกหุ้นเพิ่มหนัก,
   แผนธุรกิจเลื่อนจนเรื่องราวเปลี่ยน, โดนกฎหมายหนัก) · ราคาตกเฉย ๆ หรือราคาแพง **ไม่ใช่** ธง · ตัวที่เดือนก่อนติดธง
   ต้องตรวจซ้ำว่าเหตุผลยังอยู่ไหม ถ้าหายแล้วให้ปลดธง (`flag: null`)
5. ภาพรวมตลาด: S&P 500 เทียบจุดสูงสุด, เรื่องที่ขยับตลาดเดือนที่ผ่านมา, วันสำคัญของเดือนใหม่ (ประชุมเฟด, CPI, วันประกาศงบของบริษัทใหญ่)
6. เขียนไฟล์ชั่วคราว `/tmp/part.json` รูปแบบ:
   ```json
   { "market": { "view": "3–5 ประโยค", "points": [{"text":"…","url":"https://…","date":"YYYY-MM-DD"}], "calendar": [{"date":"YYYY-MM-DD","text":"…","url":"https://…"}] },
     "stocks": { "NVDA": { "view": "2–4 ประโยค", "points": [{"text":"ข้อเท็จจริงพร้อมตัวเลข","url":"https://…","date":"YYYY-MM-DD"}], "risk": "ความเสี่ยงหลัก 1 ประโยค", "flag": null } } }
   ```
   `flag` = `null` หรือเหตุผลภาษาไทยไม่เกิน ~12 คำ · หุ้นละ 3–5 ข้อ
7. `node scripts/build-review.mjs <YYYY-MM ของเดือนนี้> <วันนี้ YYYY-MM-DD> /tmp/part.json`
   (สคริปต์จะตัดข้อที่ไม่มีลิงก์ https และไม่ยอมเขียนทับเดือนที่มีอยู่แล้ว)
8. ทบทวน `data-src/watchlist.json`: เพิ่ม/ถอดได้ไม่เกิน 3 ตัวต่อเดือน พร้อมเหตุผลใน commit · ห้ามถอดตัวที่อยู่ใน 8 ตัวหลัก ·
   ถ้าเพิ่มตัวใหม่ให้รัน `node scripts/fetch-logos.mjs` ด้วย
9. `node scripts/fetch-data.ts` อีกรอบ (ให้ธงใหม่มีผล) → `npm test` → `npm run build` ต้องผ่านทั้งหมด
10. commit ทุกอย่างใต้ `public/data`, `public/logos`, `data-src` ด้วยข้อความ `บทสรุปเดือน <YYYY-MM>` แล้ว push ขึ้น `main`
    (push แล้วเว็บจะอัปเดตเอง)
